# Tilecheck

テキストで書いて、色の付いたマスをタップで埋めていくチェックリスト（6本目）。
持ち物・買い物・点検・段取りなど、繰り返し使うものに。

**フォルダ名・バンドルID・型名は `Mochimono` のまま。**
App ID を登録したあとに名前が「モチモノ」で押さえられていると分かり、
表示名だけ `Tilecheck` に変えた。バンドルIDは利用者に見えないので作り直していない。

## 仕様

- リストは**プレーンテキスト**で書く。1行 = 1つの持ち物。
- **空行でグループが分かれる。** グループには自動で色が付く（名前は付けない）。
- 閲覧はグリッド。グループで行は改めず、**上から詰めて並べる**（区別は色だけ）。
  セルは横長。既定4列、リストごとに2〜5列へ変更できる。
- タップで「持った」。**まだ = 淡い塗り / 持った = 同じ色相で濃い塗り。**
- チェックは**手動リセットのみ**（「全部外す」。件数を書いた確認を通る）。
- **配色はリストごとに、番号で選ぶ**（12種）。名前も説明も持たせない。
  リスト画面の **◀ ▶ で送る**だけ。設定画面からは触らせない。
  **1つ送るごとに色相が30度ずつ回る。** 一周（12回）で元に戻る。
  押すたびに全然違う色になると、目当ての色を通り過ぎて選べない。
  **同系色の濃淡と無彩色は置かない。** グループの切れ目が読み取りにくいため。
- ライト/ダークはアプリ全体（自動・ライト・ダーク）。同じ設定画面に置く。
- ジェスチャーには触覚を付ける（全アプリ共通の方針）。
- **文字サイズの設定に追従する。** 大きくすると文字もマスも大きくなり、
  文字を大きくする設定のときは**列を減らす**（減らさないと自動縮小がかかって元に戻る）。
- 読み上げでは色が伝わらないので、「持った／まだ」を言葉で持たせている。
- リストは**並べ替えられる**（一覧の「編集」）。
- **1つだけ足すのに編集画面を開かなくてよい**（リスト画面の「＋」）。最後のグループに入る。
- 通信しない。データは端末内だけ。

```
MochimonoCore/            UIに依存しないロジック（swift test で回せる）
  Color.swift             HSL・輝度・コントラスト

  Store.swift             保存するもの全部

install-device.sh         接続中のiPhoneに入れる
```

## 色の決め方（ここが要）

色は決め打ちしない。**輝度を測って**決める。3つを全モード×明暗×10グループで満たす。

| 何を測るか | 下限 | 実測の最小 |
|---|---|---|
| 塗りと文字 | 4.5:1 | 4.50 |
| まだ↔持った | 2.0:1 | 2.01 |
| 隣のグループ | 色相12°以上 | — |
| 隣の番号どうし | 20以上60以下（少しずつ変わる） | 約30〜40 |
| どの2つの番号も | 20以上（同じに見える番号を作らない） | — |

HSLの明度で白黒を振り分けると、黄や緑で必ず読めなくなる。→ `PaletteTests`
