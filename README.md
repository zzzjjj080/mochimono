# Tilecheck

テキストで書いて、色の付いたマスをタップで埋めていくチェックリスト（6本目）。
持ち物・買い物・点検・段取りなど、繰り返し使うものに。

**フォルダ名・バンドルID・型名は `Mochimono` のまま。**
App ID を登録したあとに名前が「モチモノ」で押さえられていると分かり、
表示名だけ `Tilecheck` に変えた。バンドルIDは利用者に見えないので作り直していない。

## 仕様

- リストは**プレーンテキスト**で書く。1行 = 1つの持ち物。
- **空行でグループが分かれる。** グループには自動で色が付く（名前は付けない）。
- 閲覧はグリッド。グループで行は改めず、**上から詰めて並べる**（区別は色だけ）。
  セルは横長。既定4列、リストごとに2〜5列へ変更できる。
- タップで「持った」。**まだ = 淡い塗り / 持った = 同じ色相で濃い塗り。**
- チェックは**手動リセットのみ**（「全部外す」）。**途中で押したときだけ件数つきの確認を通す。**
- **そろった帯は、そのまま押して外せる**（確認なし）。
  そろった盤面で次にやることはこれしかないので、下まで手を伸ばさせない。
- **配色の矢印とカラーの札は、盤面の下**（操作の段）。盤面を見たまま送って比べられればよい。
  矢印の間には**実際の色の見本を5つ**並べる。番号だけでは送った先が何色か分からない。
- **盤面の上は太い帯1本。進み具合・数（`6 / 20`）・そろった知らせをこれ1つにまとめる**（高さ46pt）。
  塗りは**そのリストの1色目の濃淡**（上を明るく、下を暗く）。棒だけでどのリストか分かる。
  **色相をまたぐグラデーション（青→緑など）にしない。** 混ざるあたりが濁って見える。
  文字は帯の上に重ね、**塗りの内と外で2枚に分けて色を変える**（境目で必ず読めなくなるため。
  塗りの上は配色が測って決めた文字色をそのまま使う）。
  そろうと帯が緑になり「ヨシ！ 全部そろいました」に変わって、押せるようになる。
- **そろった瞬間だけ派手に祝う。** 帯は緑の光をまとい（影＋白い縁＋斜めに走る光）、印が跳ねる。
  さらに**画面いっぱいの閃光**（緑の染め＋帯から広がる光の玉＋白い輪）を **0.5秒だけ**出す。
  最初は紙吹雪にしたが、盤面の中で小さく散るだけで手応えが薄く、やめた。**短く・画面全体で。**
  **帯の高さは変えない。** 大きく見せるのは `scaleEffect`（場所を取らない）。高さを変えると盤面がずれる。
  祝うのは「そろっていない → そろった」に変わった時だけ。開くたびに祝われると煩わしい。
  **細い棒・数字・知らせを別々に積まない。** 積むとそろった時に段が増えて盤面が下へずれる。
  右上の小さな数字（3/10）は廃止した（2026-09-16）。目が行くのは盤面で、右上は見ない。
- **下の段は「全部外す」「1つ足す」「編集」の3つ。** 記号だけの＋は何が増えるのか分からないので言葉にした。
  色は藍（編集）と墨（残り2つ）、角丸は 7pt。標準の押しボタンは丸すぎて、四角いマスと並ぶと締まらない。
- **「チェックを全部外す」を設定画面から外した**（2026-09-16）。同じ操作の入口が2つあると、
  どちらに確認が付いているのか分からなくなる。
- **配色はリストごとに、番号で選ぶ**（10種。2026-09-13 に12から減らした）。名前も説明も持たせない。
  リスト画面の **◀ ▶ で送る**だけ。設定画面からは触らせない。
  **1つ送るごとに色相が36度ずつ回る。** 一周（10回）で元に戻る。
- **カラーモード**（リストごと・既定オン）。オフにすると全グループが**配色の1色目**で塗られる。
  グループの区切り（`Item.group`）は消さないので、オンに戻せば元の色分けに戻る。
  切り替えは配色の矢印の隣（「カラー」）。
  押すたびに全然違う色になると、目当ての色を通り過ぎて選べない。
  **同系色の濃淡と無彩色は置かない。** グループの切れ目が読み取りにくいため。
- ライト/ダークはアプリ全体（自動・ライト・ダーク）。同じ設定画面に置く。
- ジェスチャーには触覚を付ける（全アプリ共通の方針）。
- **文字サイズの設定に追従する。** 大きくすると文字もマスも大きくなり、
  文字を大きくする設定のときは**列を減らす**（減らさないと自動縮小がかかって元に戻る）。
- 読み上げでは色が伝わらないので、「持った／まだ」を言葉で持たせている。
- リストは**並べ替えられる**（一覧の「編集」）。
- **1つだけ足すのに編集画面を開かなくてよい**（リスト画面の「＋」）。最後のグループに入る。
- **リストを複製できる**（一覧の行を右に払う）。写るのは書いた内容・列数・配色だけで、
  **チェックとそろった日時は持ち越さない。** 雛形より自分の盤面のほうが近い出発点。
- **全部そろった日時を残す**（`lastCompletedAt`）。一覧に「前回 今日そろった」と出る。
  **「全部外す」では消さない。** 外したのはチェックであって記録ではない。
- **手ぶらで準備できる読み上げ**（2026-09-22、1.3）。リスト画面の右上のスピーカー。
  **まだの物だけを盤面の順に1つずつ読み、3.5秒待って次へ。周が終わったら「残り◯個」と言って頭から繰り返す。**
  読んだあと「持った」で印、「次」で飛ばす、「もう一回」で読み直す、「止めて」で終わり。そろったら自分で止まる。
  - 聞き取りは**端末の中だけ**（`requiresOnDeviceRecognition`）。「通信は投げ銭だけ」を崩さない。
    端末内で聞き取れない・許可が無いときは、読むだけにして画面の「持った」「次へ」で答える
  - **聞くのは読み終えてから。** 読んでいる間も聞くと、自分が読んだ品名を拾う
  - 声で「持った」は**付けるだけで外さない**（`markPacked`）。入り切りにすると、手で付けていた物が外れる
  - 聞き分けの語は `MochimonoCore/ReadAloud.swift` の表（12言語）。**打ち消し（まだ・ない・not）を「持った」より先に見る。**
    語を足したら、ほかの合図の語を含まないか `ReadAloudTests` が全語を確かめる
  - 読み上げ中は画面を消さない。配色の段は読み上げの段に入れ替わる。読んでいる1つには枠が付き、画面に入るよう送る
  - 画面を離れる・アプリを閉じると止まる（画面を消したまま読み続ける仕組みは入れていない）
- 盤面はテキストに書き出せる（設定の共有シート）。貼り付けからも作れる。**独自の書式は使わない。**
- 投げ銭「開発者にコーヒーを奢る」は設定の中。**1.0 では出さず、1.1 で出す**（`AppFeature.showsTipJar`）。
- 書いた内容は端末内だけ。通信するのは投げ銭のときだけで、相手は Apple。マイクは読み上げ中だけ使い、聞き取りも端末内。
- **設定画面のいちばん下に入っている版の印**（`1.3 (5) · b52 09/22 10:30`）。`install-device.sh` が毎回入れる（引き継ぎ書 4-145）

## 構成

```
MochimonoCore/            UIに依存しないロジック（swift test で回せる）
  Color.swift             HSL・輝度・コントラスト
  Palette.swift           配色8種と色の決定
  PackingList.swift       テキストの解釈・チェックの引き継ぎ
  Preset.swift            雛形12種
  Store.swift             保存するもの全部
Mochimono/                Xcodeプロジェクト
  Mochimono/              SwiftUI
  MochimonoTests/         AppModel（保存と復元）
  MochimonoUITests/       セグメント・確認ダイアログ・編集
mochimono.html            HTMLプロトタイプ（操作感を固めるのに使った。雛形は入っていない）

install-device.sh         接続中のiPhoneに入れる
```

## 色の決め方（ここが要）

色は決め打ちしない。**輝度を測って**決める。3つを全モード×明暗×10グループで満たす。

| 何を測るか | 下限 | 実測の最小 |
|---|---|---|
| 塗りと文字 | 4.5:1 | 4.50 |
| まだ↔持った | 2.0:1 | 2.01 |
| 隣のグループ | 色相12°以上 | — |
| 隣の番号どうし | 20以上60以下（少しずつ変わる） | 約30〜40 |
| どの2つの番号も | 20以上（同じに見える番号を作らない） | — |

HSLの明度で白黒を振り分けると、黄や緑で必ず読めなくなる。→ `PaletteTests`
