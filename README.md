# モチモノ

出かける前の持ち物チェック。忘れ物をなくすためのアプリ。

## 仕様（2026-08-30 決定）

- リストは**プレーンテキスト**で書く。1行 = 1つの持ち物。
- **空行でグループが分かれる。** グループには自動で色が付く（名前は付けない）。
- 閲覧モードは**グリッド**。グループで行は改めず、上から詰めて並べる（区別は色だけ）。
  既定4列、リストごとに2〜5列へ変更できる。セルは横長。
- タップで「持った」。**未チェック = グループ色の淡い塗り / チェック済み = 同じ色相で濃く塗る。**
- チェックは**手動リセットのみ**（「全部外す」。確認ダイアログを通る）。
- **配色はリストごとに選ぶ**（8モード）。カラフル / にじ / 同系色 / 暖色⇔寒色 /
  くすみ / ビビッド / パステル / モノクロ。違いは「グループの色をどう選ぶか」。
- ライト/ダークはアプリ全体（自動・ライト・ダーク）。同じ設定画面に置く。
- 色は決め打ちせず、**輝度を測って**決める。文字 4.5:1 以上、未チェック↔持った 2.0 以上、
  隣のグループが紛らわしくないこと、の3つを全モード×明暗×10グループで満たす。
- リストは複数持てる。起動時は**リスト一覧**、タップで開く。
- 画面は「一覧 → リスト → 編集（中身）／設定（見た目）」の4枚。
- ジェスチャーには**触覚フィードバック**を付ける（全アプリ共通の方針）。
