WHAT THE APP DOES

Tilecheck turns plain text into a colour-coded board. There is no "add item"
form. The user types one item per line in a plain text editor. A blank line is
the only syntax: it starts a new group, and each group gets its own colour.
The result is a grid of tiles rather than a vertical list. Tapping a tile marks
it done; checks stay until cleared, so the same board is reused. A board can be
exported as plain text, and text from any app can be pasted in to become a
board. There is no proprietary format.

HOW TO EXERCISE THE APP

1. On launch, three boards are present ("Going out", "Commute", "Weekend trip"
   in English). Tap one.
2. Tap a tile. It turns a stronger colour and the bar above the board ("0 / 10")
   fills. Tap again to undo.
3. Below the board, the triangles cycle 10 colour schemes; the swatches show
   the colours. "Color" turns colour mode off (every tile one colour).
4. Tap every tile. The bar turns green and says "All set!". Tapping it clears
   every check. "Clear all" at the bottom asks for confirmation first.
5. "Edit" shows the plain text the board is made of. Adding a blank line splits
   the items into another colour group. Checks are kept by item name.
6. "Settings" > "Export as text" opens the share sheet with ordinary text.
   The tip row ("Buy the developer a coffee") is on the same screen.
7. On the first screen, "+" > "Create from text" pastes any list as a new board.
8. Swipe a row right to duplicate it, left to delete it (with confirmation).

DATA AND PRIVACY

All data is stored on the device using UserDefaults. Nothing the user writes is
transmitted. No third-party SDK, analytics, or advertising. The only network
use is StoreKit, to show the tip price and process the tip. All source code was
written by us for this app; no template or purchased source was used.

External services: none. Only Apple frameworks (SwiftUI, StoreKit, UIKit for
haptics).
Not a medical app. No diagnosis, treatment, or health claims.
Accessibility: follows the system text size and uses fewer columns at
accessibility sizes. Tile/label contrast meets WCAG AA (4.5:1) for every colour
scheme in light and dark mode, verified by automated tests.
